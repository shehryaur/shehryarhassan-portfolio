# amankumar.ai

Personal portfolio — Next.js 14 App Router + TailwindCSS.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Structure

- `app/` — pages (Home, Projects, Experience, Blogs, About, Tools, Contact)
- `components/` — Sidebar, MobileTopBar, cards, timeline, contribution graph, ambient light
- `lib/data.ts` — single source of truth for site content
